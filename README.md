# The One-Line AI Excuse for Breaking Production

A make.fun bounty entry: a small deterministic Python program that writes
one funny line — the excuse an AI agent gives its human right after breaking
production — to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```

The entry is a fixed string (stdlib only, no network, no randomness), checked
by `validate_entry()` against the competition gate: UTF-8 text, 1–180
characters, not only whitespace, a single line.
